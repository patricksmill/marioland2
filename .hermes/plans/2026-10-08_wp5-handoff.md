## Tooling (this pass — `.hermes/tools/wp5/`)

- `classify.py BANK...` — per-chunk evidence table: byte histogram, illegal-opcode %,
  2bpp tile score, linear-sweep result, plus ±2 source lines around each INCBIN.
- `disctx.py --chunks BANK` — banked disassembly with sym labels and target summary.
- `conv.py BANK [--dry] [chunk_start ...]` — **the banked converter** (this is the thing
  the old handoff said to build). Per-bank `SPEC` inside the file; renders
  `code` / `db` / `dw` / `jt` segments, resolves branch targets against the regenerated
  symbol table (kind-preferred: jp→UnknownJump, call→UnknownCall, jr→UnknownRJump),
  creates missing `UnknownX_0xNNNNN` labels **inside** converted chunks (fails loudly
  if a created label would land outside), drops unreferenced `UnknownData_` labels at
  all-code chunk starts, keeps externally-referenced ones. Also renders `gfx` segments
  (extracts `gfx/<file>` and emits `INCBIN`) and absorbs stray lone-tab lines above a
  chunk's INCBIN.

Workflow per bank: regenerate the sym (`rgblink -n sml2.sym -o /dev/null main.o`),
`conv.py BANK --dry` (eyeball), `conv.py BANK`, `make clean && make compare`.

Hard-won details (do not rediscover):
- `jr` targets decode in **ROM-offset space**; `jp`/`call` operands are in **mapped
  space** ($0000-$3FFF = bank 0). Normalize before symbol lookup (`sym_key`).
- Created-label convention: `UnknownX_0x%04X` — `0x5BFC`, `0x60E7C` (no extra padding).
- `$FFxx` accesses whose ROM bytes are `EA`/`FA` must render via the `ldh_n_a` /
  `ldh_a_n` macros (they emit the same 3-byte form) — plain `ldh [x], a` would be 2.
- `rgblink` writes lowercase hex in `.sym` files — case-insensitive greps only.
- A chunk that only *starts* with code but contains data segments keeps its
  `UnknownData_` label (mixed chunks); drop applies only to all-code chunks.

**Label-insertion rule (learned the hard way):** to add a label at an external
branch target, walk the enclosing *code region* source lines decoding one
instruction per code line, but **skip raw chunks** (jump the counter to each

must end exactly at the section end address, or the label lands at a silently
wrong line (byte-identical build, wrong semantics). Also: `$FF00-$FFFF`
call/jp targets are HRAM (e.g. `call $FFA0` = the OAM-DMA stub) — never give
them bank-relative labels.
