## The one method that works (every batch)

1. Decode semantics — statically, and live (PyBoy) whenever a name is ambiguous.
2. Add `DEF sName EQU $Axxx` lines to `ram.asm`, sorted by address.
3. Substitute **bracketed refs only** — `[$A2xx]` → `[sName]` — with
   `.hermes/tools/wp6/sub_refs.py <batch.tsv>` (dry-run first, then `--apply`);
   batch TSVs are kept in `.hermes/tools/wp6/` (e.g. `batch2.tsv`). No bare/immediate/
   comment refs exist for this page; verify with an unbracketed-ref pre-screen when in doubt.
4. `make clean && make compare && sha1sum baserom.gb sml2.gb` — commit ONLY on green,
   with the decoded semantics + live-verification notes in the commit message.
   Single-quote the message (or use `git commit -F <file>`): `$`-words inside double
   quotes get shell-eaten (cf. the mangled `d93c172` title).
